Generated literal codes are bound to their actual throw sites; [machine inventory](failure-codes.json). Native OS details and dynamic suffixes may supplement them. A failed/incomplete execution never becomes linguistic validation success.

For environment prerequisites, inspect `ud-agent doctor`; use owned setup/repair within the selected authority. Integrity/hash/identity failures block the affected path and never trigger availability fallback. A stale edit or CONFLICT requires a fresh snapshot/preview; retries retain their semantic request identity. Cancellation must finish owned cleanup or retain explicit recovery-required state. Unsupported project code in userspace requires OCI, not dependency omission. Never resolve a path/ownership rejection by granting arbitrary roots.
