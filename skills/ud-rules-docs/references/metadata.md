# Metadata proposals

`metadata_change_plan` (088) uses selected files and explicit
`proposed_metadata_path`. Preserve machine-readable conventions and unrelated
prose/comments. Distinguish omitted values from replacements/removals; review the
plan and original fingerprints.

Identity, language, contact, annotation provenance, genre and license need
authoritative values. Counts cannot establish an annotation method and product
MIT licensing does not alter a treebank's license. Ask only for the missing value
that affects the requested change.

Check candidate repository/documentation validation. Identity changes can affect
related repositories; use the dedicated rename plan instead of global text
replacement. Applying metadata is local work, not an online registry update.
Report changed fields, prior/proposed values, evidence, paths and limitations;
retain the plan/context for review or handover.
