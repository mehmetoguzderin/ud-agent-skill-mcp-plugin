# Repository work

Keep the application interfaces and existing successful CLI/MCP behavior compatible. Shared result/input contracts and generated artifacts must agree.

Use ordinary native original tests and the protected OCI runner for mutants. Never execute a generated variant with host, publisher or coordinator authority. Missing outcomes, compile/runtime errors, timeouts, skipped required cases and empty suites fail acceptance. Native foreign-platform gaps remain pending through compiler/source-bound applicability; they never count as kills or equivalent exceptions.

Run `npm run check` and focused behavior tests after changes; final acceptance runs the complete discovered inventories against one frozen source snapshot. `npm run generate` regenerates checked-in contracts and host metadata. Preserve byte fixtures, workspace grants, immutable runtime identities, private state and owned cleanup. No global engine prune, shared-service shutdown, shell-profile modification or ambient dependency installation.

Release preparation is local. Publishing, signing, remote workflow dispatch and account changes require explicit owner authority; preparing packages does not provide it. Preserve receipts and distinguish actual runtime evidence from cross-builds or fixture tests. Newly authored code uses MIT; upstream files retain their own notices and source obligations. README.md is the primary published-install guide.
